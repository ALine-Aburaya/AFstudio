AF Studio – Privacy Policy

Last updated: November 4, 2026

AF Studio is a personal desktop tool. It has no server and no user accounts of its own: all data stays on the owner's computer.

Data we access from TikTok

  • user.info.basic: display name and avatar, only to show which account is connected.
  • video.upload / video.publish: used only to upload videos the user created and scheduled.

Storage

The access token is saved in a local file on the user's computer and is never sent to anyone other than TikTok. No data is sold, shared or used for advertising.

Deletion

Clicking "Disconnect" in the app deletes the stored token. Access can also be revoked in TikTok: Settings and privacy → Security → Manage app permissions.
